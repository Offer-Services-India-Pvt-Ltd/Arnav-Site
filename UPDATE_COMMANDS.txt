=====================================
IMPORTANT COMMANDS FOR FUTURE UPDATES
=====================================

📝 STEP 1: CHECK STATUS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
git status


📝 STEP 2: ADD ALL CHANGES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
git add -A


📝 STEP 3: COMMIT WITH MESSAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
git commit -m "Your commit message here"

Example:
git commit -m "Updated pricing plans - 199 plan for 56 days"


📝 STEP 4: PUSH TO GITHUB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
git push -u origin master


📝 STEP 5: VERIFY PUSH WAS SUCCESSFUL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
git log --oneline -3
git remote -v

=====================================
IF PUSH FAILS - TROUBLESHOOTING
=====================================

❌ Permission denied (403):
Solution: Use SSH (already configured)
Check: git remote -v
Should show: git@github.com:recharge-sim-services-providers-pvt/Sachin-Studios.git

❌ SSH key not recognized:
Solution: Make sure SSH key is loaded:
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_rsa

❌ Wrong branch:
Always push to: master (not main)
Command: git push -u origin master
